#  API Data e Hora (Express + Front-end)

Projeto da **Atividade 02 — Aula 04** (Frameworks Front-end / SENAI).

## Estrutura
- `backend/`: API REST em Node.js + Express com rota `/data-hora` (deploy no Render).
- `frontend/`: Aplicação Web em HTML, CSS e JavaScript consumindo a API via `fetch()` (deploy na Vercel).
